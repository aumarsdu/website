# HIREP-CIS海报处理

使用本技能定位并移除海报中的指定视觉元素，同时尽量保持周边颜色、透明卡片和背景纹理自然连续。

## 工作流程

1. 确认用户给出的输入图像、待处理元素及处理意图。默认只分析和制定方案；仅在用户明确确认后执行图像编辑。
2. 查看原图并记录画布宽高。以左上角为原点，输出每个元素的 `x`、`y`、`宽`、`高`；坐标均为近似视觉边界时必须注明。
3. 为每个处理区域向四周扩展 2 px，并合并相邻且语义关联的元素。例如，移除二维码时同时覆盖卡片和说明文字；移除时间与日期时同时覆盖遗留的时钟图标。
4. 先给出遮挡表和处理策略，再等待用户确认。遮挡表至少包含元素、扩大后的框和建议的修复来源。
5. 使用图像编辑工具编辑原图：引用原始图像，不要重新设计整张海报。仅移除用户确认的区域，并要求自然延展相邻的背景渐变、纹理、透明度及亮度。
6. 查看生成结果并验收。发现文字残影、二维码碎片、纯色矩形、边缘色差、纹理重复或未授权的版式变化时，说明问题并生成修订版。

## 遮挡与修复规则

- 不要以纯色矩形直接覆盖；优先使用局部内容修复和 1–2 px 的无缝融合。
- 对深色背景，沿用相邻区域的暗纹理、渐变和光线方向；对半透明卡片，保留卡片底色、透明感及底层图像的明暗关系。
- 避免覆盖相邻的标题胶囊、边框、头像、正文或其他未确认元素。
- 将连续信息行作为一个修复区域，避免多个小补丁之间产生色差。
- 不要原地覆盖用户的原始图像。交付新生成文件，并报告输出路径与实际像素尺寸。

## 编辑提示词骨架

向图像编辑工具明确提供以下约束，并将方括号替换为实际内容：

```text
编辑此海报，只移除：[元素及扩大后坐标]。
使用遮挡框四周已有的[深色渐变 / 半透明卡片 / 背景纹理]自然延展修复。
不要留下文字、图标、二维码残影、纯色遮挡块、矩形边缘或色差。
除上述区域外，保持全部文字、排版、尺寸、色调和内容不变。
```

## 验收清单

- 指定元素及其关联图标、说明文字均已清除。
- 修复区与相邻区域的颜色、亮度、透明度和纹理连续。
- 修复边缘无明显矩形、模糊带、重复纹理或残影。
- 未确认区域的内容和布局未被改动。
- 已报告生成图的实际尺寸；若编辑工具改变分辨率或改动其他内容，明确说明该限制。
